# Orquestivo visual identity (locked)

The official approved design has an **infinity symbol**, **two continuous orbital arcs**, **three connected source/build/deploy tiles** (code, gear, rocket), and a **completion check**. The original is a full-color, dark-navy square with the wordmark *Orquestivo* and subtitle *CI/CD WORKFLOW STUDIO*.

## Usage contract

- **Marketplace extension icon:** `media/icon-128.png` keeps the approved complete composition at 128 × 128 px. Small-scale legibility must be validated in actual storefront and installed-extension contexts.
- **VS Code Activity Bar:** `media/activity.svg` is a carefully aligned, monochrome rendering of the same visual language (infinity, three connected stages, completion). It uses `currentColor` to follow the theme; it is intentionally simpler for 16–24 px legibility.
- **README:** `media/readme-logo.webp` is a resized, compressed derivative of the exact approved full artwork, preserving the wordmark, subtitle, original geometry and colors. This is the main logo displayed at the top. The user-approved image is the master, not the Activity Bar approximation.
- Never replace the emblem with a generic workflow symbol, circles and nodes, dollar sign, or three blank tiles.

Review the gallery icon alongside the approved source at 16, 24, 48 and 128 px and verify the sidebar in both light and dark themes. The color icon is not intended to inherit VS Code colors; the monochrome variant is.
